# Faris Research

The complete Faris Research website, with the Earth design, latest copy, original typography, header logo and footer logo. Built with plain HTML and CSS; no installation or build is required.

## View the website

Open `index.html` in your browser.

## Publish with GitHub Pages

1. Extract the ZIP.
2. Upload its contents to the root of your GitHub repository. `index.html`, `styles.css` and `assets/` must sit at the top level.
3. In the repository, open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, select your branch (usually `main`) and **/(root)**, then save.
5. GitHub will show the website address when deployment finishes.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

All asset paths are relative, so the site supports a repository subpath or a custom domain.

## Edit

- `index.html`: wording, sections and contact details.
- `styles.css`: colours, typography, spacing and mobile layout.
- `assets/faris-research-wordmark.png`: the supplied logo used in the header and footer.
- `assets/earth-upscaled.png`: the supplied Earth image, restored and upscaled using the built-in image tool.
- `assets/favicon.svg`: browser icon.

Email opens the visitor's email application. LinkedIn opens in a new tab. No scripts, trackers, forms, accounts or external font services are required.
