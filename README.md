# Faris Research — single-file website

The complete final website is contained in `index.html`. The CSS, supplied logos and Earth image are embedded in the file, so no `assets` folder is needed.

## Fix the GitHub website

1. Download and extract this ZIP.
2. Upload `index.html` to the top level of the FarisResearch repository, replacing the existing `index.html`.
3. Commit the change. After GitHub Pages finishes deploying, refresh the website.

The file can also be opened directly in a browser. The wording and layout are the same as the final updated design.
